Storing things in variables

A useful program needs to remember information. Variables give values names so you can reuse, update and combine those values instead of typing them repeatedly.

What is a variable?

A variable is a name that refers to a value. The assignment operator = stores the value on its right under the name on its left. For example, name = "Sam" stores a string and age = 18 stores an integer.

You do not declare a variable type in advance. Python works out the type from the value you assign. You can also assign a new value to the same variable later in the program.

Naming variables clearly

Choose names that explain the information they hold. Names may contain letters, digits and underscores, but they cannot begin with a digit or contain spaces. Python treats student_name and Student_Name as two different names.

Avoid names that are too short to understand. total_marks is clearer than tm. Do not use Python keywords such as if, for or class as variable names.

Reuse and update values

Once a value is stored, use its variable name anywhere that value is needed. You can combine text with commas inside print(), or create a new value from existing variables. Python evaluates the expression on the right before assigning the result.

For example, age = age + 1 reads the current age, adds one and stores the result back in age. The shorter form age += 1 does the same job.

Good to know
  • Use = for assignment; use == later when you need to compare values.
  • Do not put quotation marks around a variable name when you want its value.
  • Variable names cannot contain spaces.
  • A reassignment replaces the previous value stored under that name.

Try it yourself

The code examples above are for reference. Copy the relevant example into the editor, press Run, then change it and run it again.

# Security Policy

## About this project

Code Campuz is a front-end website made with plain HTML, CSS and a little JavaScript. It has no server, no database and no user accounts. The login page is for design only, so it doesn't store or send any real passwords or personal data.

## Supported versions

Only the latest version of the site, on the `main` branch, gets updates.

## Reporting a problem

If you find something that looks like a security issue, such as a broken link that leads somewhere unsafe, an exposed secret, or an unsafe third-party script, please tell me privately before posting it publicly.

- Use the **Contact** page on the Code Campuz website, or
- Open a private report from the **Security** tab of this repository, if it is enabled.

Please include:
- The page or file where you found it
- What you saw, and the steps to repeat it
- A screenshot, if it helps

## What to expect

- I'll reply within about 7 days.
- If the issue is real, I'll fix it as soon as I can and let you know.
- If it isn't a security issue, I'll explain why.

Thank you for helping keep Code Campuz safe for everyone.

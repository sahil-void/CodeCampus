Images and semantic layout

A web page is more than headings and paragraphs. Add images with useful alternative text and group content using semantic elements that describe the purpose of each region.

Add images correctly

The <img> element displays an image. Its src attribute identifies the file or URL, and its alt attribute provides a text alternative. Write alt text that communicates the information the image contributes.

Use a meaningful relative path when the image is part of your project, such as images/campus.jpg. A broken path means the browser cannot locate the file. The image file must actually exist at that location.

Use semantic page regions

Elements such as <header>, <nav>, <main>, <section> and <footer> describe the role of content. They do not automatically create a visual layout; CSS controls how those regions look.

Use <main> for the page’s primary content. Use <nav> around major navigation links. A section should normally have a heading that explains what the section contains.

Keep content accessible

Alternative text is not a place for keyword stuffing. For a decorative image, an empty alt="" can keep screen readers from announcing unnecessary information. For an informative image, describe its relevant purpose.

Do not use a generic <div> for every part of the page. Semantic HTML gives browsers and assistive technologies more useful information and makes your code easier for other developers to understand.

Good to know
  • Always check that the src path matches a real file.
  • Write alt text for the image’s purpose, not its appearance alone.
  • Use one main element for the main page content.
  • Semantic elements describe meaning; they do not replace CSS layout.
